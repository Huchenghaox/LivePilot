# Demo Guide

## Demo Scope

Use the current screenshot review Beta scope:

- create an account;
- create an anchor profile;
- manually record a Douyin account;
- create a pre-stream plan;
- create a screenshot review;
- manually enter key metrics if no vision model is configured;
- generate a report;
- review next actions;
- submit feedback.

Do not demo:

- official Douyin data sync as complete;
- Cookie or password login;
- automatic platform control;
- real-time audio listening;
- high-light clipping as production-ready.

## Recommended Demo Script

1. Open LivePilot.
2. Register or log in.
3. Create an anchor profile.
4. Add a manually recorded Douyin account.
5. Generate a pre-stream plan.
6. Create a live review.
7. Upload screenshots or choose manual entry.
8. Confirm key metrics.
9. Add a temporary analysis note.
10. Generate a report.
11. Show the first screen: summary, strength, main problem, three actions.
12. Mark an action status.
13. Submit feedback.

## Demo Data Safety

Use synthetic screenshots or manually entered fake metrics. Do not use real user phone numbers, private backend screenshots, API keys, or platform tokens.
