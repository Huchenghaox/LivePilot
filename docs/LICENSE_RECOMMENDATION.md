# License Decision

LivePilot is released under the GNU Affero General Public License v3.0. See `../LICENSE`.

## Why AGPL-3.0

LivePilot is intended to be public open source while still discouraging simple closed-source SaaS rebranding.

AGPL-3.0 allows people to:

- read and learn from the code;
- run the software;
- modify it;
- distribute it;
- use it commercially.

It also requires modified network-service versions to provide corresponding source code to users under the license.

## Compared With MIT

MIT is simpler and more permissive. It allows third parties to modify LivePilot and run a closed-source SaaS without sharing changes.

That is not the best fit for LivePilot's current goal.

## Compared With Apache-2.0

Apache-2.0 is also permissive and adds explicit patent language. It is friendly for broad company adoption, but it does not address closed-source SaaS copies.

## Future Commercial Licensing

AGPL-3.0 does not prevent a future dual-license or commercial-license strategy, provided the project owner has the rights needed to offer those terms.

No commercial terms are promised by this document.

This is a project decision summary, not legal advice.
